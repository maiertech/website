# AGENTS.md

A content-driven SvelteKit website. Content types are defined in [GLOSSARY.md](GLOSSARY.md).

## Verification

Before you create or update a pull request, run `pnpm verify` and fix any errors or warnings. It
regenerates the content collections and runs lint, type checks, and knip.

## Agent skills

- Issue tracker is GitHub Issues. See `docs/agents/issue-tracker.md`.
- Triage labels use the default canonical set. See `docs/agents/triage-labels.md`.
- Domain docs use the single-context layout. See `docs/agents/domain.md`.
